## 什么是机场订阅

机场通常指提供多个地区代理节点和统一订阅链接的网络服务。用户购买套餐后，将机场订阅导入 Clash、Shadowrocket、v2rayN 等客户端，就能在香港、日本、新加坡、美国等节点之间切换。机场与传统 VPN 的使用方式不同：VPN 多由单一应用直接连接，机场则更强调节点订阅、规则分流和多客户端兼容。

## 常见问题 FAQ

### 便宜机场订阅怎么导入 Clash？

登录便宜机场用户中心，在“我的订阅”中选择 Clash / Mihomo 类客户端的一键导入；手动导入时，应复制完整订阅链接到客户端的订阅管理页面。

### 小火箭、Loon 或 Surge 更新失败怎么办？

先关闭代理，确认客户端是较新版本，再从便宜机场官网重新复制订阅。不要在浏览器或聊天软件里打开订阅链接。

### 软路由可以使用便宜机场吗？

OpenWrt、iStoreOS、OpenClash、PassWall、HomeProxy 等环境能否直接使用，取决于插件版本和订阅协议。请按便宜机场教程中的软路由说明配置。

### 节点全部超时一定是机场故障吗？

不一定。本地网络、运营商线路、客户端版本、旧订阅缓存和代理未关闭都可能造成超时。可先更新订阅、切换本地网络，再提交工单排查。
